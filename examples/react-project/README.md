# Example: React project

A minimal Vite + React + TypeScript front end (customer claims portal) used to
demonstrate and test the AI harness. It ships with an existing `AGENTS.md`
that `setup.sh` must preserve, and no project context, so setup creates one
from the template with the detected stack filled in.

```bash
cp -R examples/react-project /tmp/react-demo
./scripts/setup.sh /tmp/react-demo
```
